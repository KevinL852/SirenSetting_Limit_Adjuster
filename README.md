# SirenSetting_Limit_Adjuster_updated
SirenSetting_Limit_Adjuster for FiveM 'updated' for use up to gamebuild 3717 (mp2025_02) 'A Safehouse in the Hills'

This is an 'updated' version of cp702's SirenSetting Limit Adjuster 2.0.2 plugin.

I did not create this plugin, I only added support for newer FiveM gamebuilds.
You can find the original/NOT UPDATED plugin here: https://www.lcpdfr.com/downloads/gta5mods/scripts/28560-sirensetting-limit-adjuster/

This plugin raises various siren limits in GTA V/FiveM.

### How to install the plugin:
1. Click this link: https://github.com/KevinL852/SirenSetting_Limit_Adjuster/releases or click the release on the right.
2. Find the latest release or for your gamebuild and click 'Source code (zip)'. It is recommended to always use the latest release as it'll work on older gamebuilds anyway.
3. Open the "FiveM Application Data" folder and navigate to the 'plugins' folder. If you don't have a plugins folder, create one.
4. Drag & drop the 'SirenSetting_Limit_Adjuster_bXXXX.asi' from the .zip downloaded on step 2, into the plugins folder and you should be good to go.
